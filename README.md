# WS.Remote

Remote support from **WS.COMPUTER**. Free. By GRUENCY.

**Install:** [gruency.com/apps/remote-install](https://gruency.com/apps/remote-install) — Windows 10/11 and Mac (Apple silicon and Intel, macOS 14 or later), with a one-line install command or the file to download.

## How it works
1. Install and open WS.Remote. A window shows **your support number** (9 digits). Tell it to WS.COMPUTER Support.
2. When they connect, you'll see a window with the WS.COMPUTER logo and *Verified WS.COMPUTER technician*. Click **Allow**.
3. A small bar at the top of the screen shows the session is on. Click **End** at any time.

### Permissions on Mac
WS.Remote asks for **Screen Recording** and **Accessibility** so the helper can see the screen and use the mouse. macOS lets only you switch these on, once.

## Privacy and security
- The support connection exists only while the support window is open (max. 1 hour without a session). Apart from that the app only checks for updates every 30 minutes.
- Updates are accepted only when signed by WS.COMPUTER and matching the published checksum.
- The picture, mouse and keyboard are encrypted between the two computers (ECDH P-256 + AES-256-GCM).
- Only a verified WS.COMPUTER technician can connect; every request needs your **Allow**.
- No account, no tracking.
