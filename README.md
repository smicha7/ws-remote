# WS.Remote

Remote support from **WS.COMPUTER**. Free. By GRUENCY.

**Download for Windows 10/11:** [WS.Remote.exe](https://github.com/smicha7/ws-remote/releases/latest/download/WS.Remote.exe) — short link: **gruency.com/remote**

**Download for Mac** (Apple silicon M1 and newer, and Intel; macOS 14 or later): [WS.Remote.dmg](https://github.com/smicha7/ws-remote/releases/latest/download/WS.Remote.dmg) — short link: **gruency.com/remote-mac**

## How it works
1. Download and open `WS.Remote.exe`. No installation needed.
2. A window shows **your support number** (9 digits). Tell it to WS.COMPUTER Support.
3. When they connect, you'll see a window with the WS.COMPUTER logo and *Verified WS.COMPUTER technician*. Click **Allow**.
4. A red bar at the top of the screen shows the session is on. Click **End** at any time.

### First start on Windows
The file is not yet signed with a paid Microsoft certificate, so Windows may show *"Windows protected your PC"*.
Click **More info → Run anyway**. It appears once.

### First start on Mac
Open the .dmg and drag WS.Remote to Applications. On the first start macOS may say it can't verify the app: open **System Settings → Privacy & Security** and click **Open Anyway**. WS.Remote also asks for **Screen Recording** and **Accessibility** so the helper can see the screen and use the mouse.

## Privacy and security
- Nothing runs in the background: the app connects only while the support window is open (max. 1 hour without a session).
- The picture, mouse and keyboard go **directly between the two computers**, end-to-end encrypted (ECDH P-256 + AES-256-GCM).
- Only a verified WS.COMPUTER technician can connect; every request needs your **Allow**.
- No account, no tracking.
